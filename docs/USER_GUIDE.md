## 首页

### 1. 仪表盘

**做什么用**：打开应用后的第一屏，把「还剩几天考试、今天吃了多少、打卡进度如何」一屏看全，并提供最常用的快捷操作，省去逐个模块点进去的麻烦。

**怎么用**：

1. 登录后默认进入仪表盘，顶部是各场考试的倒计时卡片（天/时/分/秒实时跳动）；
2. 中部「卡路里环」显示今日已摄入与剩余额度，鼠标悬停可看具体数值；
3. 「打卡进度」列出今日待打卡的习惯，可直接在卡片上勾选；
4. 底部「快速操作」提供一键开番茄、记体重、写日记等入口，点击即跳对应模块；
5. 每日一句卡片每天轮换一条语录，点击可前往「每日一句」收藏。

**小技巧**：仪表盘会实时响应你在其他模块的记录（记完一餐、打完卡，回到仪表盘立刻刷新），把它当作「今日自律总控台」即可，不需要刻意操作。

## 学习

### 2. 考试倒计时

**做什么用**：给自己一点「看得见的压迫感」。支持多场考试同时管理（考研、四六级、期末、自定义），实时倒计时 + 总进度条 + 阶段里程碑。

**怎么用**：

1. 进入「考试倒计时」，默认已预置「2027 考研」（2026-12-19），可在卡片上直接编辑改期；
2. 点击「添加考试」，填写名称、目标日期，可选颜色与图标，保存后卡片出现并开始实时跳动；
3. 每张卡片下方有总进度条：从你设置的起始日到考试日的整体进度；
4. 距考试 200/100/30 天时，卡片会自动显示「强化期 / 冲刺期 / 考前冲刺」里程碑标签；
5. 已过期的考试会进入「已结束」分区，可一键归档，或改期「复活」继续用。

**小技巧**：把四六级、期末考也加进来，多场考试按剩余天数自动排序，一眼知道先急哪场。

### 3. 番茄专注钟

**做什么用**：核心学习计时工具。正/倒计时皆可，完成一个番茄 = 一棵树 + 5 自律币，专注时长全部进入统计热力图。

**怎么用**：

1. 进入「番茄专注钟」，可自定义专注时长（默认 25 分钟）与休息时长（默认 5 分钟）；
2. 填写本次专注的标签（如「英语阅读」「数学强化」），点击开始；
3. 需要沉浸时点击「全屏专注模式」，页面只剩计时器；
4. 可在专注页联动开启白噪音（详见白噪音模块）；
5. 计时结束自动记录一条专注历史，并在「数据统计」累计。

**小技巧**：别贪长。先用 25 分钟建立「坐得住」的感觉，稳定后再调到 45/60 分钟。中断了就老实重来，数据诚实才有效。

### 4. 待办清单

**做什么用**：把「今天要做什么」拆清楚。支持考研任务与日常事务分开，四象限优先级配色、子任务拆解、完成动效。

**怎么用**：

1. 进入「待办清单」，点击「添加任务」，输入内容；
2. 为任务选择优先级（四象限：重要紧急/重要不紧急/紧急不重要/不重要不紧急），不同象限不同配色；
3. 大任务可添加子任务，逐项勾选，全部完成后任务自动算完成；
4. 可设置截止日期，到期任务会高亮提示；
5. 勾选完成时有撒花动效，完成的任务可随时删除或恢复。

**小技巧**：睡前花 3 分钟写好明天 3 件「重要不紧急」的事，比早起再想要高效得多。

### 5. 备考知识库

**做什么用**：学累了刷两条。考研常识 + 减脂科普的知识卡片库，每天轮换推送，既补信息差又不动摇心态。

**怎么用**：

1. 进入「备考知识库」，首页展示今日推送的卡片；
2. 浏览卡片内容（考研报名流程/复试常识/减脂误区/营养学小知识等）；
3. 点击「换一张」随机抽取新卡片；
4. 读过的卡片会记录已读状态，方便回看。

**小技巧**：每天一两张就够，知识库是调味品不是主食，别用它逃避刷题。

## 体重

### 6. 卡路里记录

**做什么用**：减脂的核心是热量差。三餐 + 加餐全记录，内置 400+ 常见食物库，摄入环直观显示今日额度还剩多少。

**怎么用**：

1. 进入「卡路里记录」，选择餐次（早餐/午餐/晚餐/加餐）；
2. 在搜索框输入食物名（如「鸡胸肉」「米饭」），从 400+ 食物库中选取；
3. 填写克重，自动计算热量与三大营养素；找不到的食物点「自定义食物」手动录入；
4. 页面上方「摄入环」实时显示今日已摄入 / 剩余额度；
5. 支持按日期回看与修改历史记录。

**小技巧**：中餐估重不必纠结精确到 5 克——连续记录两周后你对份量的直觉会准很多。记录的完整性比单条精度更重要。

### 7. 体重管理

**做什么用**：体重曲线 + BMI 计算器 + 体脂估算 + 目标进度，用数据代替体重秤上的情绪。

**怎么用**：

1. 首次进入先在「个人资料」里填写身高、目标体重、性别、年龄、活动水平；
2. 每天固定时间（建议晨起空腹）点击「记录体重」，输入数值，可选填体脂率；
3. 曲线图自动绘制，支持回看任意时间段趋势；
4. BMI 计算器根据身高体重实时计算，并给出体脂估算；
5. 「目标进度」显示距目标体重的剩余量与完成百分比。

**小技巧**：体重每天波动 1-2 斤是水分不是脂肪。看周均线，别看单日数字。

### 8. 运动消耗

**做什么用**：记录运动消耗，与饮食摄入算净值。内置跑步、跳绳、力量训练等常见运动库，按时长与强度自动计算消耗。

**怎么用**：

1. 进入「运动消耗」，点击「添加记录」；
2. 从运动库选择运动类型（跑步/跳绳/游泳/力量等）；
3. 填写时长，系统按运动强度系数自动估算消耗热量；
4. 保存后与当日卡路里摄入联动，页面展示「摄入 - 消耗」净值；
5. 支持按日期查看历史运动记录。

**小技巧**：每日 300-500 kcal 的热量缺口最可持续，靠「吃」为主、「动」为辅，而不是反过来。

### 9. 喝水记录

**做什么用**：考研久坐容易忘记喝水，减脂期充足饮水还能控制假性饥饿。每日目标 + 快捷杯量 + 7 日柱状图。

**怎么用**：

1. 进入「喝水记录」，默认每日目标 2000ml，可在设置中调整；
2. 点击快捷杯量按钮（如 250ml / 500ml）一键记录，每次 +1 杯；
3. 今日进度条实时更新达标百分比；
4. 底部 7 日柱状图展示最近一周的饮水量变化；
5. 配合「提醒中心」设置喝水间隔提醒，避免一坐一下午忘喝水。

**小技巧**：在图书馆固定用一个有刻度的水杯，记录速度翻倍。

### 10. 睡眠记录

**做什么用**：睡眠是学习效率与减脂共同的底层。记录就寝/起床时间、时长统计、质量评分与 7 日趋势。

**怎么用**：

1. 进入「睡眠记录」，点击「添加记录」；
2. 填写昨晚的就寝时间与起床时间，自动计算时长；
3. 给昨晚睡眠质量打 1-5 分；
4. 保存后可在 7 日趋势图中查看时长与质量的波动；
5. 长期记录可以发现「睡不够 → 第二天暴食/效率低」的规律。

**小技巧**：固定起床时间比固定入睡时间更容易做到，先锁起床，入睡自然前移。

## 记录

### 11. 日记簿

**做什么用**：备考期情绪波动大，写下来就好一半。Markdown-lite 编辑、心情 + 天气标签、日历回看、全文搜索、字数统计。

**怎么用**：

1. 进入「日记簿」，点击「写日记」；
2. 输入标题与正文（支持 Markdown-lite：加粗、列表、引用等简单语法）；
3. 为今天选择心情与天气标签；
4. 保存后自动统计字数，写一篇日记 +3 自律币；
5. 可通过日历视图按日期回看，或在搜索框全文检索。

**小技巧**：不用写长，每天三句话——今天做成了什么、卡在哪、明天第一件事做什么。

### 12. 习惯打卡

**做什么用**：把「坚持」变成看得见的连续天数。自定义习惯、streak 连击、21 天养成进度、补卡机制。

**怎么用**：

1. 进入「习惯打卡」，点击「添加习惯」，设置名称、图标、颜色与目标频率；
2. 每天完成就在卡片上打勾，streak 连续天数自动累计；
3. 卡片显示 21 天养成进度条，满 21 天视为初步养成；
4. 断了一天？可消耗自律币补卡（详见自律币经济），连续天数得以保住；
5. 每次打卡 +2 自律币。

**小技巧**：习惯从「小到不可能失败」开始：「背 10 个单词」比「背 200 个」更容易撑过 21 天。

### 13. 日历总览

**做什么用**：一个月的自律全貌。月历整合视图，用四种颜色标记打卡、日记、体重、专注记录。

**怎么用**：

1. 进入「日历总览」，默认显示当月；
2. 有记录的日期会出现对应颜色的标记点（打卡/日记/体重/专注各一色）；
3. 点击任意日期查看当天的详细记录汇总；
4. 可切换上/下月回看历史，也能发现「连续摆烂周」并及时拉回。

**小技巧**：月底扫一眼颜色密度，比翻十页数据报表更能说明这个月的真实状态。

### 14. 数据统计

**做什么用**：所有坚持的量化呈现。GitHub 风学习时长热力图、周/月报表、卡路里趋势、体重趋势与综合图表。

**怎么用**：

1. 进入「数据统计」，顶部为学习时长热力图（GitHub 风格，颜色越深专注越久）；
2. 切换周报/月报查看专注时长汇总与对比；
3. 查看卡路里摄入趋势图，识别周末暴食等规律；
4. 查看体重趋势曲线，配合目标进度复盘减脂速度；
5. 综合图表区展示各维度数据的联动关系。

**小技巧**：每周日晚上看一次周报即可，天天看数据反而焦虑。热力图「别断颜色」本身就是最好的动力。

### 15. 专注森林

**做什么用**：Forest 的免费替代。每完成一个番茄种一棵树，树随专注时长成长，稀有树种随累计专注解锁，最终长成你的森林全景。

**怎么用**：

1. 每完成一次番茄钟，自动种下一棵树，专注越久树越大；
2. 进入「专注森林」查看自己的树 collection；
3. 累计专注达到一定时长后解锁稀有树种（不同形态/颜色）；
4. 森林全景页展示所有树的整体景观；
5. 点击单棵树可查看种植日期与对应的专注时长。

**小技巧**：期末冲刺季回来看一眼森林全景——那是你一天一天坐出来的，没有任何水分。

### 16. 目标管理

**做什么用**：把「考研 380 分」「减到 60kg」这种长期目标拆成可执行的阶段里程碑，进度随时追踪。

**怎么用**：

1. 进入「目标管理」，点击「添加目标」；
2. 填写目标名称、类型（考研分数/目标体重/自定义）、目标值与截止日期；
3. 将大目标拆解为若干阶段里程碑（如「一轮复习完成」「减 5kg」）；
4. 填写当前进度值，系统自动计算整体完成百分比；
5. 完成一个里程碑就勾选，看着进度条往前走。

**小技巧**：里程碑要「可验收」：「数学一轮」不如「高数 18 讲刷完 + 错题本建好」。

## 激励

### 17. 成就系统

**做什么用**：30+ 枚成就勋章，覆盖连续打卡、累计专注、体重里程碑、日记达人等维度，每枚解锁 +10 自律币。

**怎么用**：

1. 进入「成就系统」，查看勋章墙：已解锁的勋章点亮，未解锁的显示解锁条件与当前进度；
2. 正常使用各模块即自动触发解锁（无需手动领取）；
3. 解锁瞬间有全局提示，勋章永久保留；
4. 点击勋章可查看达成日期与达成条件。

**小技巧**：进度条快满的成就在「勋章墙」上有提示，差一点点的那个往往就是今天多坚持一轮番茄的理由。

### 18. 自律商城

**做什么用**：把自律变成看得见的奖励。用自律币兑换你为自己许下的心愿——一杯奶茶、一场电影、半天假，规则你自己定。

**怎么用**：

1. 自律币通过日常行为自动入账（番茄 +5、打卡 +2、日记 +3、体重 +2、成就 +10）；
2. 进入「自律商城」，先在「心愿单」里添加奖励项并标价（如「奶茶一杯 = 50 币」）；
3. 币够了就点击兑换，系统记账并扣币；
4. 兑换历史在记录列表中可查；
5. 心愿要真的兑现给自己，这是整套经济系统的信用基础。

**小技巧**：小奖励定价 30-80 币（约一周攒齐），大奖励 300+ 币（月度目标）。太容易换到就失去了约束力。

### 19. 每日一句

**做什么用**：150+ 条语录（考研上岸 + 减脂 + 自律），每天一条，状态崩了就来抽一张。

**怎么用**：

1. 进入「每日一句」，展示今日推送的语录；
2. 点击「换一张」随机切换；
3. 点击「收藏」把喜欢的句子加入收藏夹；
4. 收藏夹可随时回看，仪表盘的每日一句卡片与本模块联动。

**小技巧**：把最戳你的一条收藏起来，截图设成手机壁纸，比任何鸡汤都对症。

## 系统

### 20. 提醒中心

**做什么用**：久坐是考研人的职业病。喝水/站立/久坐提醒，浏览器通知 + 页面内浮条，间隔自定义。

**怎么用**：

1. 进入「提醒中心」，分别开启喝水/站立/久坐提醒；
2. 设置提醒间隔（如喝水每 45 分钟）；
3. 首次开启时浏览器会请求通知权限，允许后即使页面在后台也能收到系统通知；
4. 页面在前台时以浮条形式提示，不打断当前操作；
5. 随时可暂停或修改任意提醒。

**小技巧**：图书馆环境不适合频繁响铃，可以只开「页面内浮条」不开系统通知，静音自律。

### 21. 白噪音

**做什么用**：图书馆/宿舍隔音差？用 Web Audio 实时合成的白噪音盖住环境音：雨声、海浪、森林、键盘、翻书、棕噪音。

**怎么用**：

1. 进入「白噪音」，点击任意音景即可播放（纯合成，无音频文件，秒开）；
2. 可同时开启多个音景并分别调节音量，调出你的专属混合（如「雨声 60% + 键盘 20%」）；
3. 在番茄钟专注页可直接联动开启；
4. 再次点击或切到静音即停止。

**小技巧**：棕噪音（低频）更适合掩盖嘈杂人声，雨声更适合入睡。搭配睡前记录一起用。

### 22. 数据管理

**做什么用**：你的数据你做主。导出/导入 JSON 备份、数据清空、云同步状态查看。

**怎么用**：

1. 进入「数据管理」，点击「导出备份」下载全部数据的 JSON 文件，建议每月一次；
2. 换设备或重装浏览器后，点击「导入备份」选择 JSON 文件即可完整恢复；
3. 「数据清空」需二次确认，清空前请务必先导出；
4. 若配置了 Supabase，此处显示云同步状态。

**小技巧**：把备份文件存进网盘/发给自己一份，双保险。**换电脑、清缓存之前，先导出。**

### 23. 主题系统

**做什么用**：好看才想每天打开。深色/浅色/自动三模式、6 种主题色、护眼模式，设置持久保存。

**怎么用**：

1. 进入「设置 → 主题」，或使用顶栏的主题快捷切换按钮；
2. 模式选 light / dark / auto（auto 跟随系统深浅色自动切换）；
3. 6 种主题色任选：indigo（默认）/ sakura / mint / ocean / sunset / amber；
4. 晚上刷题眼睛累可开启「护眼模式」（暖色滤镜）；
5. 所有设置自动持久化，下次打开保持原样。

**小技巧**：白天 indigo 深色自动，晚上加护眼模式——这是多数用户的最终配置。

### 24. 账号系统

**做什么用**：本地账号（注册/登录/游客）+ 可选 Supabase 云账号双模式，密码 SHA-256 加盐存储。

**怎么用**：

1. 首次访问在入口页注册：账号 + 密码（≥8 位，需含字母和数字）；
2. 不想注册就点「游客模式」，直接进入应用；
3. 游客可随时在应用内「账号」页升级为正式注册账号，已有数据无缝保留；
4. 需要多设备同步时，在设置中配置 Supabase 云账号（见 docs/DEPLOY.md）；
5. 退出登录 / 切换账号在底部用户卡或账号页操作。

**小技巧**：密码忘记无法找回（本地模式不存明文），请用记得住的密码，或注册后立刻在「数据管理」导出一份备份。

### 附录 C：常见问题 FAQ

**1. 我的数据存在哪里？**
默认 100% 存在你当前浏览器的 localStorage 中，不上传任何服务器。只有你主动配置 Supabase 后才会同步到你自己的云数据库。

**2. 换设备 / 换浏览器怎么办？**
两条路：一是在「数据管理」导出 JSON 备份，到新设备导入；二是配置 Supabase 云同步，登录同一账号自动拉取。未配置云同步且没导出备份，数据不会跨设备跟随。

**3. 忘记密码怎么办？**
本地模式密码经 SHA-256 加盐存储，无法找回。可以注册一个新账号（旧数据仍在本浏览器中，可尝试登录其他记住密码的账号后导出）。预防方案：注册后立刻导出一份备份。

**4. 游客模式能升级成正式账号吗？**
能。在应用内「账号」页选择注册升级，当前游客数据无缝保留，不需要重新记录。

**5. 怎么开启深色模式？**
顶栏主题快捷按钮一键切换，或在「设置 → 主题」中选择 light / dark / auto。auto 会跟随系统深浅色自动变化。

**6. 字体太小 / 界面太密怎么办？**
设置中提供「护眼模式」（暖色滤镜）与「紧凑密度」开关；同时浏览器本身支持 Ctrl/Cmd + 加号缩放页面，研轻为响应式布局，缩放不会破版。

**7. 怎么导出备份？**
「系统 → 数据管理 → 导出备份」，下载完整 JSON 文件。建议每月定期导出，并在换设备、清缓存、重装浏览器之前必导出。

**8. 支持哪些浏览器？**
Chrome / Edge / Safari / Firefox 的现代版本，含 iOS Safari。不支持 IE。需要支持 ES Module 与 localStorage 的环境即可。

**9. 云同步安全吗？**
云同步使用你自己在 supabase.com 创建的项目，数据存你自己的数据库；密码经 Supabase Auth 处理，研轻不接触明文。不配置云同步时，没有任何数据离开你的浏览器。

**10. 卸载 / 清除浏览器数据后记录还在吗？**
清除浏览器缓存与站点数据会同时清掉 localStorage，记录将丢失。因此：卸载或清理前，务必先在「数据管理」导出 JSON 备份；有云同步的账号在重新登录后会自动恢复。
