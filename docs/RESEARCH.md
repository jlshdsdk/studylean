# 研轻 StudyLean — 竞品调研报告

> 调研目的：在「考研自律 × 健康减脂」赛道上明确研轻的定位、借鉴对象与差异化壁垒。
> 调研方式：国内社区（B站测评视频评论区、知乎高赞回答）+ 海外应用市场趋势（2026 habit tracker 功能趋势）。
> 说明：本报告结论服务于产品设计，数据引用来自公开社区内容，个别播放/点赞量为调研当时快照，可能随时间变化。

## 一、竞品逐个分析

### 1. 番茄ToDo

- **优势**：界面简洁，计时稳定，国内学生群体渗透率高，「学霸模式」强制专注有一定威慑力。
- **劣势**：核心数据报表逐步会员化（周报等收费点被用户反复吐槽）；功能偏单线计时，与饮食/体重完全割裂；广告与会员引导影响体验。
- **可借鉴**：学霸模式的强制感设计思路。
- **研轻对应**：番茄统计全免费；专注数据与卡路里/体重同屏联动。

### 2. Forest 专注森林

- **优势**：「种树」隐喻深入人心，游戏化激励标杆；养树心理契约对轻度拖延者有效。
- **劣势**：核心功能（树种、解锁）重度付费墙；付费树种的多样性仍有限；统计维度较浅。
- **可借鉴**：把抽象的专注时长变成可积累的具象资产（树/森林全景）。
- **研轻对应**：专注森林完全免费，树种随累计专注解锁；统计维度更细（热力图、周月报、跨模块联动）。

### 3. CoStudy

- **优势**：线上自习室氛围感强，「虚拟自习室 + 同桌陪伴」切中了备考孤独感；界面与校园场景契合。
- **劣势**：氪金换装商城是用户最大槽点——装扮、座位数等付费点让「陪伴」变了味。
- **数据支撑**：B站「岷|线上自习App横向测评」（约 31 万播放、823 评论）评论区中，对 CoStudy 氪金换装体系的反感是高赞反馈之一，用户普遍认为自习工具不应靠皮肤收费。
- **研轻对应**：无任何氪金商城；专注氛围通过全屏专注模式 + 白噪音 + 森林动画实现，激励货币（自律币）只通过自己的坚持赚取。

### 4. 薄荷健康

- **优势**：中餐食物库覆盖广，体重曲线与热量控制成熟，是国内减脂记录的事实标准之一。
- **劣势**：会员功能持续增多；无任何学习/备考场景；广告与电商化（卖代餐）稀释工具属性；用户在意的数据本地性弱。
- **可借鉴**：食物库结构（名称 + 克重 + 三大营养素）与体重目标进度设计。
- **研轻对应**：400+ 常见食物库 + 自定义食物；数据本地存储；并叠加考研场景（倒计时同屏、专注与热量联动）。

### 5. 食卡卡

- **优势**：拍照/搜索记热量门槛低，对「懒得估重」的用户友好，界面年轻化。
- **数据支撑**：知乎「减肥期我只推荐一个App」回答（53 赞）中对食卡卡的识别便捷性给予明确认可，属于口碑型小众推荐。
- **劣势**：识别精度有限（中餐混合菜仍是老大难）；部分高级功能收费；同样无学习场景。
- **研轻对应**：不追求 AI 识别噱头，用「食物库搜索 + 自定义食物 + 摄入环」把手动记录做到最低摩擦，并强调「记录完整性 > 单条精度」的用户教育。

### 6. 体重小本

- **优势**：轻量纯粹，记体重体验顺手，曲线简洁。
- **劣势**：功能单一（仅体重维度），无营养、运动、目标拆解的闭环。
- **研轻对应**：体重模块（曲线 + BMI + 体脂估算 + 围度 + 目标进度）与卡路里/运动形成热量闭环。

### 7. Habitica（海外）

- **优势**：RPG 游戏化鼻祖——完成任务升级打怪，激励机制体系最完整。
- **劣势**：上手门槛高（RPG 术语与界面劝退轻度用户），英文产品对国内学生本土化不足，界面陈旧。
- **可借鉴**：完整的经济系统（赚币 → 消费 → 稀有奖励）。
- **研轻对应**：自律币经济（番茄+5/打卡+2/日记+3/体重+2/成就+10 → 商城兑换自定义心愿），规则中文、轻量、一眼看懂。

### 8. Streaks（海外）

- **优势**：连续打卡（streak）机制与 Apple 设计奖级别的交互打磨。
- **劣势**：iOS 付费买断；打卡维度单一，无内容生态。
- **可借鉴**：streak 连击的心理价值与 21 天习惯养成框架。
- **研轻对应**：习惯打卡 streak + 21 天养成进度 + 补卡机制（消耗自律币），且热力图把 streak 可视化到全年维度。

### 9. 柠檬喝水

- **优势**：喝水提醒这一单点做到极致，提醒策略与杯子量设计贴心。
- **劣势**：广告较多，功能外延有限。
- **研轻对应**：喝水模块（每日目标 + 快捷杯量 + 7 日柱状图）并入提醒中心（喝水/站立/久坐），无广告。

### 10. 潮汐

- **优势**：专注 + 白噪音 + 冥想的氛围感标杆，设计与声音品质公认优秀。
- **劣势**：核心音景与高级统计订阅制；无饮食/体重维度。
- **可借鉴**：白噪音对专注场景的沉浸价值。
- **研轻对应**：白噪音用 Web Audio 实时合成（雨声/海浪/森林/键盘/翻书/棕噪音），支持多音景混合与专注联动，零素材成本、全免费。

## 二、用户核心痛点（跨竞品汇总）

| 痛点 | 来源与证据 |
|---|---|
| **氪金会员** | CoStudy 氪金换装（B站 31 万播放测评评论区高赞反感）、Forest 付费树种、番茄ToDo 周报收费、潮汐订阅制。调研中被吐槽频率最高的单一痛点 |
| **广告** | 柠檬喝水等免费产品的广告插入，破坏记录心流 |
| **陪伴感缺失** | 自习类产品的走红本身就证明孤独是备考最大敌人之一；但现有方案（CoStudy）用氪金换装兑现陪伴，方向跑偏 |
| **中餐估重难** | 薄荷/食卡卡用户普遍反映混合中餐克重难估，AI 识别对中餐精度有限，导致记录中断、半途而废 |
| **坚持不下来** | 所有记录类 App 的共同流失原因：反馈太慢、维度太散（学习一个 App、吃饭一个 App，两边都坚持不了） |

## 三、研轻的差异化

1. **双线融合**：考研专注与饮食体重同屏管理。学习时长热力图与卡路里环在同一仪表盘，这是单一赛道的竞品都给不了的「一站式」价值——用户只需要坚持打开一个 App。
2. **全免费**：无会员、无氪金商城、无广告。自律币经济完全由用户自己的行为驱动（赚币 → 兑换自己许下的心愿），不存在「付费买坚持」。
3. **本地隐私**：数据默认仅存浏览器 localStorage，无埋点无追踪。在「记录体重/饮食」这类高敏感场景下，本地化是明确的信任优势。
4. **打卡 + 补卡**：Streaks 式 streak 机制之上提供自律币补卡，承认「人会失误」，用小惩罚（扣币）代替「一天断掉全部归零」的挫败——这是留存设计的关键。
5. **热力图**：GitHub 风学习热力图把全年坚持压缩成一张图，「别断颜色」是比任何勋章都直观的长期动机。

## 四、海外趋势参考（2026 habit tracker 功能趋势）

结合海外应用市场近年的产品演进方向，四个趋势与研轻路线图的关联：

1. **AI insights（洞察生成）**：从「记录」走向「解读」——自动总结周报、识别「熬夜 → 暴食」类关联。研轻的本地数据结构已为此留好接口，可作为后续无隐私代价（数据不出本地）的增强方向。
2. **Wearable（可穿戴接入）**：步数/心率/睡眠自动同步成为海外新品标配。研轻当前以手动记录为主，接入需外部 API，暂不纳入零依赖架构，保持关注。
3. **习惯叠加（Habit stacking）**：把新习惯挂在既有习惯之后（「午饭后背 20 词」）的行为科学方法在海外产品中产品化。研轻的习惯打卡与待办四象限可自然承载该玩法。
4. **社区监督（Community accountability）**：海外趋势从纯记录转向小组打卡/互相监督。研轻坚持本地隐私优先，社区功能与该原则冲突，暂不引入；以「自律币 + 成就 + 森林」的自我反馈体系替代社交压力。

## 五、结论

竞品验证了两个需求真实存在且巨大——「备考需要专注工具」「减脂需要记录工具」——但市面产品把两条线割裂开，且普遍用会员/氪金/广告变现。研轻以「双线融合 + 全免费 + 本地隐私」切入，用打卡补卡与热力图解决「坚持不下来」的核心流失问题，定位清晰，差异化成立。
